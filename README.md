# Projects

A collection of personal projects, included as git submodules. Each one has its own README with more detail — this page is just a quick overview.

## [SplitEven](https://github.com/Leo-Haker/spliteven)

Full-stack web application for splitting shared expenses and calculating balances between members of a shared account. Built with Java, Spring Boot, React, and PostgreSQL, including automated tests and a CI pipeline in GitHub Actions.

**Stack:** Java · Spring Boot · React · PostgreSQL · JPA · JUnit · GitHub Actions

## [news-and-stock](https://github.com/Leo-Haker/news-and-stock)

A personal dashboard for tracking news and OMX30 stock prices.
**Stack:** Rust

## [Cosmere](https://github.com/Leo-Haker/Cosmere)

An early-stage project to build an interactive world set in Brandon Sanderson's Cosmere universe. Primarily a learning project for getting comfortable with C and the raylib library.

**Stack:** C · raylib

## [Calculator](https://github.com/Leo-Haker/Sommar2025)

A calculator built in C, created as a way to learn the language and practice implementing arithmetic operations from scratch.

**Stack:** C
